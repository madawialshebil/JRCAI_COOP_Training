# Task 02 - Classical Machine Learning

This task focuses on understanding and implementing classical machine learning algorithms using Python and Scikit-learn.

## What This Task Covers

- Linear Regression
- Logistic Regression
- Decision Trees
- Random Forest
- Support Vector Machines (SVM)
- K-Nearest Neighbors (KNN)
- Naive Bayes
- K-Means Clustering
- Regression, classification, and clustering
- Strengths, limitations, and suitable applications of different algorithms

Practical Python examples were implemented to demonstrate the behavior and application of the studied machine learning algorithms.

- `ML_Algorithms.pdf` - Classical Machine Learning presentation
- `ML_Algorithms.ipynb` - Jupyter Notebook implementation
- `ML_Algorithms.py` - Python script
