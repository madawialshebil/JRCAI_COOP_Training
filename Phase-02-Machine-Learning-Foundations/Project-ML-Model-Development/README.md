# Phase 02 Project - Machine Learning Model Development

This project demonstrates complete machine learning workflows across regression, classification, and clustering problems.

## What This Project Covers

### Regression
The Diabetes dataset was used to develop and compare regression models.

### Classification
The Breast Cancer Wisconsin dataset was used to develop and compare classification models.

### Clustering
The Iris dataset was used to demonstrate K-Means clustering.

The project includes:

- Data preprocessing
- Exploratory Data Analysis (EDA)
- Feature preparation
- Model development
- Model comparison
- Quantitative evaluation
- Performance visualization
- Interpretation of results

- `ML_Model_Development.pdf` - Project presentation
- `ML_Model_Development.ipynb` - Jupyter Notebook implementation
