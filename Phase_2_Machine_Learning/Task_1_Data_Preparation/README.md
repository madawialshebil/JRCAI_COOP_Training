# Task 1 — Data Preparation

## Objective

This task focuses on preparing datasets for machine learning by applying data exploration, cleaning, preprocessing, transformation, and feature preparation techniques.

## Topics Covered

- Dataset loading and inspection
- Exploratory Data Analysis (EDA)
- Missing value detection and handling
- Duplicate record detection
- Outlier detection and treatment
- Categorical variable encoding
- Feature scaling
- Normalization and standardization
- Feature engineering
- Dimensionality reduction where appropriate

## Practical Work

Assignment 2 from BIT3343 Data Mining and Knowledge Discovery was completed as the practical implementation for this task.

The assignment involved applying data preparation and preprocessing techniques using Python and machine learning libraries.
