# Phase 4 — AI Domains and Advanced Deep Learning

This phase focused on applying advanced Machine Learning and Deep Learning techniques to sequential and time-series data.

## Temperature Forecasting Project

The project evaluated multiple classical Machine Learning and Deep Learning models for temperature forecasting using time-series weather data.

### Objectives
- Prepare sequential weather data for forecasting.
- Develop and compare classical Machine Learning and Deep Learning models.
- Evaluate models using appropriate regression metrics.
- Identify the strongest ML and DL approaches for further optimization.

### Models Evaluated

#### Classical Machine Learning
- Linear Regression
- Random Forest
- XGBoost
- Support Vector Regression

#### Deep Learning
- LSTM
- GRU
- Bidirectional LSTM (BiLSTM)

### Evaluation Metrics
- RMSE
- MAE
- R²
- Prediction accuracy within ±1°C

### Key Result
Random Forest achieved the strongest performance among the classical Machine Learning models, while BiLSTM achieved the strongest Deep Learning performance and the best overall forecasting result.

The selected Random Forest and BiLSTM models were carried forward to Phase 5 for further optimization and efficiency evaluation.
