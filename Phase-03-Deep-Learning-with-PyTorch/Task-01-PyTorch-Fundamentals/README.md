# Task 01 - PyTorch Fundamentals

This task focuses on learning the fundamental concepts and components of PyTorch required to build, train, and evaluate machine learning and deep learning models.

## What This Task Covers

- Introduction to PyTorch and its ecosystem
- Tensors and tensor operations
- Tensor reshaping and broadcasting
- Computational graphs
- Automatic differentiation using Autograd
- Dataset and DataLoader
- Mini-batch processing
- PyTorch model implementation
- Loss functions and optimizers
- Model training and validation
- Model checkpointing
- Model evaluation

The Breast Cancer Wisconsin dataset was used to demonstrate a complete PyTorch data and training workflow.

## Files

- `PyTorch_Fundamentals.pdf` - PyTorch Fundamentals presentation
- `PyTorch_Fundamentals.ipynb` - Jupyter Notebook implementation
- `PyTorch_Fundamentals.py` - Python script
